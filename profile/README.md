# Srishti GenAI

**Production AI for businesses — AI agents, RAG systems, LLM applications and AI workflow automation.**

Srishti GenAI is a generative AI and software engineering company based in Bengaluru, India. We design, build and deploy AI systems that work inside real business workflows: agents that run multi-step processes across business tools, retrieval-augmented assistants grounded in private documents, and LLM features inside existing applications.

## What we work on

- **AI agents** — multi-step workflows across CRM, ERP, ticketing and internal tools, with guardrails and human approval where it matters
- **RAG systems** — retrieval grounded in approved content, with evaluation and traceability
- **LLM applications** — LLM features integrated into existing products and internal tools
- **AI workflow automation** — document-, ticket- and approval-heavy processes
- **Custom AI/ML** — from data preparation to deployment

## How we build

Short pilots with written acceptance checks, then phased rollout. We build for operations teams to use and for IT and compliance teams to govern: access controls, decision logs and measurable quality.

Main tools: Python, Anthropic Claude and OpenAI APIs, Azure and AWS.
